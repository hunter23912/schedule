# 课表工坊

一个用来录入大学课程、整理单双周安排，并导出手机长图的个人课表工具。课表只保存在当前浏览器，也可以下载 JSON 文件做备份。

## 本地运行

```sh
npm install
npm run dev
```

## 使用方式

1. 选择“添加课程”，填写课程名称、星期、起止节次和上课周次。
2. 可以为同一门课添加多个上课时段，也可以在“课表设置”里修改学期周数和节次时间。
3. 点击课程卡片可以再次编辑；同周课程时间重叠时课表会显示提示。
4. 选择“导出 PNG”查看图片预览，再下载到设备。
5. 使用“备份”和“恢复”导出或导入 JSON 课表文件。

周次支持“每周”“单周”“双周”、`1-8` 和 `1-8,11-16` 等写法。

## 构建

```sh
npm run build
npm run preview
```
